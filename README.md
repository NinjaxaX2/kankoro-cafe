# Kankoro Cafe

A premium cafe experience website for Kankoro Cafe located at CR Park Market No. 2, New Delhi.

## Features

- **Responsive Design**: Optimized for all devices (mobile, tablet, desktop)
- **Coffee Menu**: Explore our premium coffee selection
- **Food Menu**: Fresh vegetarian cuisine including pizzas, pastas, sandwiches, and more
- **Interactive UI**: Smooth animations, lightbox gallery, and expandable menu details
- **Accessibility**: WCAG compliant with keyboard navigation and screen reader support
- **Performance**: Optimized loading times, lazy image loading, and smooth scrolling

## Project Structure

```
kankoro-cafe/
├── index.html          # Homepage
├── menu.html           # Full menu page
├── about.html          # About Kankoro Cafe
├── contact.html        # Contact & visit info
├── css/
│   └── style.css       # Main stylesheet
├── js/
│   └── main.js         # Interactive features
├── data/
│   └── menu-data.js    # Menu data structure
├── dishes/             # Individual dish pages (dish-01.html to dish-50.html)
├── images/
│   └── dishes/         # Dish images (SVG)
└── README.md
```

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Explore the menu and learn about Kankoro Cafe
